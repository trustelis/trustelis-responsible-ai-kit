# Roadmap — proposed, not yet implemented

## v0.1.0 — MVP ready for review

- Python stdlib-only local check, guard wrapper and clear verdicts.
- Four reference enforcement factors: authorization, action limits, trusted data classification and human oversight.
- Minimal non-sensitive decision records (in memory only).
- Four advisory factors that clearly say NOT_EVALUATED.
- Use Case policy JSON, Control Card, CLI, Python API, custom factor hook.
- Synthetic refund agent examples, automated tests, GitHub Actions definition.

## v0.2 — developer friction reduction (proposed)

- TypeScript integration and optional framework adapters.
- Factor JSON schema and simpler onboarding.
- Offline threat-simulation compatibility with the existing independent benchmark.
- Declarative control templates, clearer explanations, deterministic test suite and semantic versioning.

## v0.3 — ecosystem validation (proposed)

- External developer feedback and compatibility matrix.
- Better adapter boundaries and structured on-device test reporting.
- Verified third-party security review if funding allows.

## Enterprise platform boundary

The commercial TRUSTELIS Control Engine, policy authority, provider capability resolver, approvals, budget, runtime gateway and Trust Pack remain **private**. The open-source kit may later be an independent onramp, not a reimplementation of the enterprise control plane.
