# Security policy

This repository provides *reference developer preflight tooling*, not production-grade authorization, legal compliance checks or protection against real attacks. No public bug bounty or bounty reward is offered.

To report a potential security issue, contact **admin@trustelis.com** without including secrets, personal records, or live exploit details. Please allow a reasonable opportunity to investigate before publishing a proof of concept.

Never run synthetic examples against production systems, accounts or third-party services. See [Threat Model](docs/THREAT_MODEL.md).
